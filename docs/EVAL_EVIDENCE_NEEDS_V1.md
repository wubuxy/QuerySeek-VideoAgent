# 按证据缺失选择观察（2026-11-07，事前冻结）

用户复核指出对象指代、物品归属和单帧静态属性问题。此轮实现部分证据保留与观察路由，本轮已完成，结果见文末。原v1/v2记录和人工反馈不回填，推理不读取答案标签或人工说明。

## 方法与对照

- 复用锚点修复后固定的60候选、480基础观察，8个已多次使用的开发来源。准备SHA固定；候选初判前，每题只看原问题生成目标、关系和single_view/temporal/global需求，8次调用。
- 60候选分别核验：未观察目标、目标歧义、关系未确认、属性不可读、时间关系不足、全局不足、显式矛盾或支持答案。除未观察目标外保留实际索引；支持静态属性允许单帧，时间问题要求不同源PTS。互斥schema与后置校验共同约束结构，不保证语义正确。
- 固定排序均匀补看和证据路由共用同一份计划、初判和基础图。每策略每题最多1次补看及核验；如果已有一致支持答案则直接回答。原排序策略选首个非global不足候选并均匀增加16帧。
- 路由优先已识别目标（关系/属性/时间不足），其次歧义目标，最后未观察目标；同级按原排序。属性或指代不足时按模型选择的重叠粗网格裁切已观察帧，增加1张局部图，保留原图。关系/时间不足时围绕所引帧前24秒、后8秒增加16帧。无目标线索才均匀补看。未观察不等于矛盾，不删候选。
- 裁切复用Pillow，不生成/修复图片内容。所有图仍用65536像素预算；局部视图增加局部可见比例，非任意框定位器。裁切与全图共享源PTS，不构成两个时刻。时间上下文按视频边界截断，可扩展原候选范围，最终回答区间相应使用实际观察范围，单独报告定位。
- 每个分支从相同初态独立执行。两策略动作完全相同则复用同一结果并清空重复成本。最多8计划+60初判+16补看=84调用，零重试/训练/新CLIP编码。记录真实token、图像/视觉token、生成和加载时间；两策略并非严格相同视觉预算或相同信息量。

## 判定与停止

先跑合成Mock、引用/裁切身份/预算/时间边界/真实parser测试。冻结源码与配置后跑一轮完整8来源，不根据中途分数改门槛。全分母计入失败和弃答，分别报告QA、接受率、接受答案准确率、区间IoU、初判结构错误、动作选择变化及成本。离线只读重放动作和指标；不能把合法状态或模型声称目标出现当人工正确率。

本轮只诊断机制。与旧v2相比同时有锚点保留、证据需求及提示/结构变化，不能作单因素因果归因。两新策略共用初态，只能比较所冻结的完整观察策略；收益不能归因于某一单独组件。人工参与过的8来源不作独立泛化结论；不把人工提供的答案或对象提示注入原题。全局需求保守弃答，当前局部实验不解决全片first/last。对象归属仍由模型主张，需要定性复核。

代码：`queryseek/retrieval/evidence_needs.py`、`scripts/probe_evidence_needs.py`。配置：`configs/evidence_needs_v1.json`。完成后在文末追加实测，事前字节保存在源码包。
