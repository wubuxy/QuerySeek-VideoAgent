# 本地视频证据工作台

2026-11-19 第一批实现：上传保存、持久任务、定位、证据回放、导出与下载。复用既有检索与 Agent；未实现新的学习控制器，Mock 不代表真实视觉准确率。

## 启动

需要 Python >=3.11、FFmpeg/ffprobe 和项目依赖：

```powershell
.venv/Scripts/python.exe -m pip install -e ".[dev,agent]"
.venv/Scripts/python.exe -m streamlit run app/streamlit_app.py --server.address 127.0.0.1
```

打开终端打印的本机地址，通常为 `http://127.0.0.1:8501`。默认使用 Mock；不需要密钥和 GPU。

## 使用

1. 在“视频库”选择 MP4/MKV/MOV 和可选 SRT，点击“保存到视频库”。同名不同内容分开保存，同内容复用原视频。
2. 可先“建立 / 更新索引”，也可以直接定位时自动准备索引。侧边栏切换已保存视频；已有 CLI 注册视频也会列出。
3. 选择执行方式、定位方式和适用的独立帧预算，填写事件描述后运行。E4/semantic 使用全视频视觉索引，帧预算不限制该索引成本。
4. 定位结果支持查看浮点秒半开区间、从区间起点播放原视频、查看证据图片和已有执行记录，下载结果与成本 JSON。
5. 展开“导出片段”，生成并下载 MP4；目标片长为 0 时导出全部候选区间。实际时长以结果为准。导出失败不会改写已经保存的定位结果。
6. 在“历史任务”打开旧结果，或保留 `?run=<任务ID>` 地址。页面刷新、新会话和服务重启后，历史记录仍在。

同一页面的重复运行请求复用已有任务；要按同参数重新执行，先点击“允许按当前参数重新运行”。关联上次定位会记录父任务 ID，但当前仍按新事件描述独立重新搜索；不是已经实现的局部补看控制器。

Mock 不识别真实图片。上传任意视频并提供 SRT 后，选择“检索与剪辑 / subtitle”可以离线验证完整流程；视觉 Mock 需要生成器提供的内容提示。普通上传不凭空生成提示。也可先运行仓库的 `scripts/make_synthetic_fixture.py`，通过 CLI ingest 生成的 sample 视频及字幕，再从页面选择已注册样本。

真实视觉模式额外需要 embedding 依赖和实际模型后端；配置 VLM_API_KEY、VLM_BASE_URL、VLM_MODEL 环境变量。页面会显示配置的模型，并提示可能调用外部服务；缺少密钥时依赖 VLM 的真实流程明确拒绝运行，不静默切换 Mock。视觉检索首次可能加载/下载 OpenCLIP 权重。

## 存储与恢复

- 上传媒体与字幕版本：`outputs/library/media/<服务生成ID>/`。
- 视频和任务元数据：`outputs/library/workspace.sqlite`，使用 SQLite 事务。
- 定位任务：`outputs/<job_id>/result.json`、`metrics.json`、`trace.jsonl`；Agent 另有任务独立 checkpoint。
- 证据图片：任务目录中的 `evidence/` 副本，不依赖日后可能被改写的索引帧。
- 每次导出使用新的产物目录；历史任务保存最近一次成功导出的引用，旧导出文件不被覆盖。
- 注册表、派生索引仍使用显式配置的 data/cache 根目录。更新字幕后强制刷新对应索引，旧定位 JSON 和图片快照保持原样。

`QUERYSEEK_OUTPUT_ROOT`、`QUERYSEEK_DATA_ROOT`、`QUERYSEEK_CACHE_ROOT` 可配置根目录。更换输出目录会切换整个工作台库，不会自动迁移旧库。视频、结果、数据库、缓存和密钥均不提交 Git。

任务状态与导出状态分开。进程锁保证本机工作台操作顺序执行；检测到已无活动执行者的旧 running/queued 记录时标记 interrupted，保留记录供新任务重跑。当前 UI 不提供在途取消或从历史任务自动续跑 checkpoint，也不宣称强制中断模型请求。

## 当前边界与验证

- 当前是本机单用户应用，不是公开托管或多用户服务；没有账号与公网隔离功能。
- 已有证据保留来源，但新的逐条假设状态契约、块树和学习动作评分器仍未接入。
- 当前保存现有策略提供的去重帧 ID 数、VLM 逻辑调用和处理耗时；尚未按源 PTS 统一合并帧，HTTP 重试、token 和累计图片展示也未统一汇总。缺失值为 null/未知，不写成零。处理耗时包含该任务中的索引准备。
- 无结果、候选相关性与“整片不存在目标”是不同结论；时间引用合法不保证事件语义正确。
- 实测：当前工作区完整 pytest 为 245 passed / 6 skipped；独立发布副本的工作台专项为 21 passed。合成视频保存、字幕定位、真实 FFmpeg 导出、刷新与新会话历史恢复已验证。跳过项涉及固定分词器、符号链接权限和不可用的外部官方评测源码，不是新工作台功能的跳过。
- 真实浏览器视觉与下载操作的自动化检查未完成：computer-use 因无法可靠识别 Windows 浏览器 URL 而中止。HTTP 健康检查与 AppTest 不替代该项检查。
