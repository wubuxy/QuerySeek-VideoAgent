# 保留视觉信息与引用复读修正（2026-11-08）

本轮已完成，结果追加于文末。本轮按“复现问题 → 修改实现 → 回归 → 真实对照”的顺序推进，不重复旧实测，也不覆盖其源码。用户要求发现问题后先修正再测。冻结后不据中途分数改提示、条件或分母。

## 修正内容与边界

旧fact_map把16图压成最多320字符，第二步只看文字；前轮事实错读、遗漏及跨语言指代问题会直接传递。新增`queryseek/retrieval/grounded_reader.py`：最终作答重新看到全部原图、原始问题和选项，旧事实仅作不可信上下文；达到320字符的事实显式标为可能不完整。允许按语义对应不同语言中的同一对象，重新选择引用；不编写题目专用规则，不改旧事实或GT。

随后只向复读器展示拟提交的引用帧和原题/选项，不展示提议答案或事实笔记。它独立输出选项或弃答、局部索引；应用层将局部索引绑定回原帧及真实PTS。仅当同答且引用合法时接受复读结果，拒答/分歧/格式错误不能回填原答案；上游已弃答不追加调用。该检验仍使用同模型，只检验在引用子集上的回答一致性，不证明引用的因果必要性或语义充分性。

两项修正分别记录为`visual_remap`和`citation_checked`。第一项纠正原图被丢弃的信息路径；第二项防止未经引用子集检查的回答直接提交。这是候选修复，真实性能需要下述对照确认，不能在测试前声称模型的误识别已解决。

## 冻结对照

- 沿用上一轮16个来源（原开发8、新来源8），现在全部视为已使用的开发回归数据；原分组仅用于追溯，不叫新的独立确认。
- 同BF16 Qwen3-VL-8B-Instruct、SDPA、16个原有oracle帧、每图262144像素、贪心512输出token、零重试。模型revision/配置和父运行输入哈希锁定。
- 每组正来源及相同循环错来源，32个输入组合。最简、compact、旧fact_map的既有结果复用，不重跑。每个组合复用旧fact第一步，然后新运行一次visual_remap；若非弃答，再最多一次引用复读，共最多64次新调用。
- 旧事实步骤计入各方法逻辑成本，但不计新物理调用；citation_checked复用visual_remap，不重复生成。全分母报告有效/作答/正确/错误作答、错来源作答与配对得失、耗时和token。新增帧/媒体/训练均为0。
- 所有原图和引用检查输入保留图像SHA/真实PTS/pixel tensor摘要。第二次图片必须等于前次引用子集，索引重新编号仅限内部，外部保持浮点秒。答案只由独立evaluate读取，推理不读标签。
- OOM或连续3后端错误打开熔断，剩余组合保留失败分母；预算在每次调用前检查。禁止将格式错误修复成答案。

### 修正效果与采用结论

两个历史分组合计16题仅作开发回归描述：旧文字映射作答8题、正确4题、错误作答4题；保留原图后作答13题、正确8题、错误作答5题，新增正确4题、未丢失原正确。错来源作答由1/16增至2/16，说明修正信息通路恢复了部分能力，但没有彻底解决无依据作答。

相对更强的最简基线，修正结果仍是8/16对9/16；相对compact为8/16对8/16，逐题有得有失，且修正的逻辑调用含复用事实步骤，成本更高。因而只确认原图信息被丢弃的问题已经在实现上修正、旧两步方案得到回归改善，不宣布超过强基线，也不据本轮将新方案升为产品默认。

引用子集复读使正确数从8降到5，过滤3个正确选项和1个错误作答；尚有4个错误作答在同模型复读后保留。这里的“正确”指选项与标注一致，并非人工认定引用充分：不能把3次过滤全部当作误拦，也不能把两次同答当作可靠证据认证。复读不作为默认硬否决门槛，保留为研究诊断。原索引到复读局部索引的转换和真实时间绑定经回归与47份实际输入核对，不再将格式正确等同语义充分。

事后逐题查看显示，一个已有静态属性误读在重新看图后被纠正；另有事件后续、时长和复合对象问题恢复作答。显式跨语言规则没有修复全部跨语言失败，中间笔记仍可能影响注意力。这些是待进一步定位的语义现象，没有单因素消融，不能归因于某句提示或单纯模型大小。

本轮完成的是修正闭环：先改变信息传递和引用检查实现，再补回归、冻结并运行同输入对照。旧协议、代码和原始输出全部保留；没有事后换题、改标签、覆盖失败或选择性报告。已使用的16来源不能重新标为独立确认，下一轮若改方法仍应明确开发回归与独立验证边界。
