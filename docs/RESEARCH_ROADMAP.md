## 1. 当前证据与评价的修正

- 已有 Qwen3-VL-8B 语言层 QLoRA，384 训练来源、32 开发来源、128 确认来源，1536 轨迹、4050 动作状态、1014 更新。
- 已用公开 QVHighlights 数据的内部来源留出；不是自建 80 条题，但也不是官方完整测试榜单或独立外部盲测。
- 历史完整测试记录是 450 passed / 2 skipped；这不是本次重新运行的结果。
- 已有 Streamlit Demo 和调用数、token、图像展示、训练耗时等记录；实际账单与完整服务延迟仍未完整核实。
- 39% 指旧 qwen3.8-flash、6 查询/96 帧诊断中 31/79 个 GT 外帧被判相关。它不是当前策略的系统假阳率；GT 外也不天然等于语义负例。当前真实负查询能力尚未验证。

值得接受的批评：尚未证明比简单强系统更划算；长视频 grounded QA 尚未完成；方法相对已有工作的新增贡献尚不清晰。评分不是录用概率，更不能据此给出候选人百分位或学校背景的录用保证。

## 2. 当前强基线与缺口

同一 128 来源内部确认、数值为百分数：

| 方法 | R1@0.5 | 比较用途 |
|---|---:|---|
| NF4 基座 + 固定 16 帧 | 30.47 | 基座直接定位 |
| SFT + 固定 16 帧 | 64.84 | 当前最强内部系统参照 |
| NF4 基座 + 回退 | 14.06 | 训练前对照 |
| SFT + 只能深入 | 30.86 | 对同一适配器禁用动作的机制消融 |
| SFT + 回退 | 57.42 | 当前搜索策略 |

回退平均 3.141 次生成，固定组 1 次；相同独立帧上限不是同实际成本。禁止回退组从错误半区出发时不能访问其他半区，也没有单独训练专用适配器，不能当作最优前向方法。

必须建立的竞争方案：

1. **全局直接回答**：同一骨干、合理输入形式、不同预设预算；保留零样本与任务微调版本。当前多图输入与官方原生视频输入须分开记录，不能把输入变化归因到搜索机制。
2. **E4 检索 + 固定二阶段验证**：候选窗口去重并保留全局覆盖，交给相同回答模型；索引构建、候选特征读取及验证成本分别计入。
3. **固定探索流程**：相同可用动作、初始信息和最大预算，按固定规则补看/切换；用于区分学习决策与增加观察的收益。
4. **VTS 参考**：按官方接口做可核查的推理基线；资源适配与原配置分开。官方 SFT/RL 训练、公开权重对照、复现分数均尚未完成。

系统比较允许各方案合理优化，回答实际选哪个系统；机制比较固定骨干、工具、输入协议与训练来源，回答单项改动是否有效。独立帧数、累计展示、视觉 token、全部模型调用、延迟均报告，不能只选对自己有利的成本口径。

## 3. 论文给出的启发及不能冒称的创新

| 一手来源 | 与本项目直接有关的设计 | 本项目应如何使用 |
|---|---|---|
| [VideoAgent, Wang et al., 2024](https://arxiv.org/html/2403.10517v1) | 从全局概览开始，判断信息是否足够，再检索缺失信息 | “按需检索/缺失信息”已有先例；其自评置信度可作停止规则参照 |
| [VideoTree, CVPR 2025](https://arxiv.org/html/2405.19209v3) | 查询相关的层级表示及不同深度的观察分配 | 保留全局概览、减少冗余；不能把一般粗到细结构称为新算法 |
| [VideoMind](https://arxiv.org/html/2503.13444v3) | 定位、局部复看验证、回答的能力分工 | 优先复用局部验证思想；不直接堆多 Agent 或宣称复现 Chain-of-LoRA |
| [VTS, 2026](https://arxiv.org/html/2607.16189v1) | 场景树、回退/切换动作、绕路轨迹、SFT 后 RL | 回退和绕路训练是参考来源；将其作为相关竞争方法 |
| [CG-Bench](https://arxiv.org/abs/2412.12075) | 答案与证据联合评测，揭示单独答对的局限 | 优先用于 grounded 长视频问题，而非只补一个 QA 准确率 |

以上为阅读与设计依据，本轮没有复制新的论文源码或运行其方法。不能从摘要的成绩跨数据、跨模型直接比较；本文亦不宣称所提假设具有未经系统检索确认的原创性。

## 4. 唯一优先研究假设

**在相同骨干与真实成本约束下，根据当前证据估计“继续观察的预期收益”，能否比固定补看和模型自报置信度更好地决定补看区域、观察粒度与停止？**

“证据缺口驱动搜索”已有相关工作。候选增量应具体落在：可监督的收益估计、可校准的停止决策，以及严格的效果—成本证据。当前均未测。

设当前可见状态为 s、候选观察为 a，拟研究的决策量是：

`预期联合正确率增量(s,a) - λ × 追加实际成本(s,a)`。

这是目标定义，不是现成可用的概率模型。λ、预算和阈值只能在开发数据上选择；展示完整曲线，不能用单一 λ 掩盖退化。训练可读取训练标签构造结果监督，部署状态不得包含 GT 或未观察画面的答案。

### 4.1 先做好可控起点

主评测从完整视频概览或真实检索候选出发；自然错误保留。哈希错误半区只作为压力测试，不用于代表实际用户分布。先保留多个合理候选，不因一轮判断过早排除其余视频。

第一个实现候选仅提供有限选择：停止回答、补全局覆盖、补看候选附近短片段、切换候选。先复用现有工具，不同时新增复杂树、长期记忆和新编码器。

### 4.2 监督应与可见信息相容

当前 AnnotationTeacher 通过完整训练 GT 选择几何最优路线；某些选择可能无法由模型当时的局部画面唯一推断。它是合法的特权监督，但“专家知道去哪”不等于“学生有线索知道去哪”。

拟先在训练来源检查：可见证据是否足以支撑唯一动作；对于方向未知状态，允许探索或多个等价动作。后续训练数据优先覆盖当前策略真实访问过的错误状态，不只使用规则绕路。

收益标签应来自训练/开发来源中候选观察后的实际答案与证据变化，记录其模型版本、观察成本和不确定性。不能让 teacher 使用测试标签或让线上策略读取未来画面。该数据构建涉及真实推理开销，应在之后另行估算，当前不执行。

### 4.3 单独处理“相关”与“足够”

缺少区域覆盖、缺少动作过程、缺少边界/先后关系是不同观察需求。优先比较同区域、同预算的稀疏图片与连续短片段，观察到差异后再训练粒度选择。

Verifier 必须对具体证据引用负责；摘要不能代替原始证据。当前连续区间接口不能直接支持跨多个不连续事件的推理，若任务要求多证据，应先定义多区间输出和官方评分适配，不能把中间无关内容全部包进去。

R2 决策：若给正确片段也答不好，优先改善局部表示/任务对齐；若候选里没有证据，优先召回与覆盖；若已有证据却答错/误停，优先验证与停止。只有追加观察存在稳定可利用收益，才值得训练收益控制器。

R3 不以“用了更复杂方法”为成功：须在预设实际预算点上提高联合质量，或在预设质量容差内降低成本。无收益则保留更简单系统并发布负结果，不为维持 Agent 名称继续堆模块。

## 6. 数据、评测与成本

- 主任务优先 CG-Bench grounded QA。沿用已准备的版本资料，但 VTS 发布的 1137 题过滤集不是完整 CG-Bench mini，必须区分。
- 官方查询划分与严格来源隔离实验分开报告。本地审计已经发现 VTS 发布训练/评测同源；不能因此直接断言同题泄漏，也不能称其为源隔离盲测。
- 后续选择真实媒体和划分前固定规则；开发样本用于调试，确认样本禁止据结果反调。旧 128 来源确认集不再用于新设计选模；现有 fresh80 也不替代长视频 QA。
- pilot 只验证运行与错误类型，不将 100 道任意子集当作完整泛化结论。确认规模按主差异、来源聚类方差和可负担成本预先规划。
- 主指标遵循官方答案与证据联合指标，同时保留 QA、定位、失败、弃答分母。不得仅以 IoU 代理语义真实性。
- 负查询需要确认“视频中不存在目标”，不能以未标注片段或打乱查询自动充当负例。报告误答率同时报告正查询拒答率、覆盖率和选择性风险，避免全拒答获得好分。
- 冷启动：解码、建库、树/描述生成及查询推理分别计时；热查询：缓存读取、检索及推理分别计时。报告单视频单查询与多查询摊销场景，不能只报摊销后的低成本。
- 统计独立帧、重复图像展示、视觉/文本 token、VLM/LLM/验证器全部调用、同硬件延迟分布及显存。实际费用只有账单或明确计价依据时才报告。
- 采用来源配对置信区间；来源 bootstrap 不覆盖训练随机性。候选方法确定后再安排重复训练，不先铺开昂贵网格。

## 7. 暂不优先的方向

暂不把 RL、扩大骨干、多 Agent、全量 caption、增加定位头容量列为默认下一步。它们分别可能放大奖励漏洞、成本、错误传播或既有过拟合。是否进入这些路线，应由 R2/R3 的具体证据决定。

字幕/音频支持单独定义赛道；不能让某方法额外获得字幕却归因到视觉搜索。外部泛化优先在主结论成立后选择一个适配的数据集，不同时扩展多个 QA/定位任务。

下一步先把回答器在可观测信息下的行为测清楚：区分局部对象/计数、连续动作、首次/时长/组合上下文；对相同图像单独检查选项提示格式，再按预先固定规则检查时域扩展和局部连续观察，不在同一组同时改所有因素。保留全部失败与不确定类别，不把开发题筛成容易题。
全局稀疏原生输入会合并相隔较远的帧并赋平均时间。它可以用于全局线索，但不能把平均时间当成真实观测时刻或精确边界。后续固定“检索→连续观察→回答/边界细化”需分别计量定位、理解、边界和调用成本；再决定动作选择是否值得学习。上述后续比较尚未执行，无新增收益结论。
